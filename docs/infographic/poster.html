1 Problem and goal

Users type "Book me a flight from Guangzhou to Lima". The answer needs the cheapest route through hubs, correct distances and prices, and a booking only when the user agrees. An LLM reads the request well, but may invent a number or take "ok, thanks" as "yes, book".

Goal: let the LLM talk, let code compute every number, and let only the user's click book.

5 Choices

  • Own loop → Pydantic AI Slim. Stop closes the upstream stream (0.6 ms on DeepSeek); tracing is standard. Booking stays our code. ADR-001
  • OpenTelemetry → Phoenix, optional; no export by default. ADR-001
  • SQLite, one worker. PostgreSQL once a second instance or more writes are needed. §7.4
  • A real airline adds schedules, seat inventory, fares, payment and PNRs behind airline/. §7.2

4 Results

  1. Same model, two providers: indistinguishable in quality and tokens; Bailian has a longer p95.
  2. Qwen3.8-flash passes fewer runs (91.1%), uses about 2× the reasoning tokens and is slower.
  3. Every failure was a trajectory deviation that cannot book; cost per successful task $0.0008 on the official API.
